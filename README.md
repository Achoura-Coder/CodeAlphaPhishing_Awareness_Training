## 📋 Overview

Phishing is the **#1 cyberattack vector** in the world today, responsible for 91% of all breaches. This project delivers a comprehensive training program designed to help anyone — from employees to executives — recognize, defend against, and report phishing attempts.

The training combines two complementary deliverables:

- 📊 A **professional slide deck** for classroom or boardroom presentation
- 🌐 A **standalone interactive quiz** for self-paced learning

---

## ✨ What's Inside

### 📊 Presentation (`Phishing_Awareness_Training.pptx`)

A 32-slide deck with a dark cybersecurity theme covering:

- **What is phishing?** — Definition, statistics, scale of the problem
- **6 types of phishing** — Email, spear, whaling, smishing, vishing, clone
- **Red flags & recognition** — 8 warning signs to memorize
- **Anatomy of attacks** — Dissecting real phishing emails and URLs
- **Social engineering** — The 6 principles of influence (Cialdini)
- **Real-world cases** — Twitter 2020, Google/Facebook BEC, Sony Pictures
- **Best practices** — Do's and Don'ts for individuals
- **Incident response** — What to do if you've already clicked
- **Quiz section** — 5 questions with detailed explanations

### 🌐 Interactive Quiz (`phishing_quiz.html`)

A standalone web application with:

- 🎯 **10 realistic scenarios** covering email phishing, BEC, URL inspection, vishing, smishing, and social engineering
- 📊 **Live progress tracking** with progress bar and running score
- 💡 **Instant feedback** — detailed explanation after every answer
- 🏆 **Animated results screen** with score circle and 5-tier verdict system
- 📝 **Full answer review** showing your choices vs. correct answers
- ⌨️ **Keyboard shortcuts** — press `1-4` to answer, `Enter` to advance
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- 🌑 **Dark cybersecurity theme** matching the presentation

## 🚀 How to Use

### Run the Interactive Quiz

No installation needed — just open the HTML file in any modern browser:

```bash
# Method 1: Double-click the file
phishing_quiz.html

# Method 2: Open from command line
start phishing_quiz.html       # Windows
open phishing_quiz.html        # macOS
xdg-open phishing_quiz.html    # Linux
```

### View the Presentation

Open `Phishing_Awareness_Training.pptx` in Microsoft PowerPoint, Google Slides, Keynote, or LibreOffice Impress.

## 🎯 Learning Outcomes

After completing this training, learners will be able to:

1. ✅ **Recognize** the 8 most common phishing red flags in emails
2. ✅ **Inspect URLs** correctly to identify spoofed domains
3. ✅ **Understand** the psychological tactics used by attackers
4. ✅ **Apply** best practices for daily security hygiene
5. ✅ **Respond** appropriately if they suspect they've been phished
6. ✅ **Test** their knowledge through realistic scenarios
